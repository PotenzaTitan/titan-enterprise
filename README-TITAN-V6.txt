POTENZA TITAN — WEBSITE UPDATE V6
=================================

This is a STATIC WEBSITE UPDATE PACKAGE for the existing Netlify/GitHub repository.
It does not publish changes automatically.

IMPORTANT:
- This package intentionally updates the website copy and layout to the new direct mill purchase model only.
- Existing folders such as assets/images, assets/logos, and documents are NOT included. Keep those folders in the existing repository.
- Before replacing files, make a backup copy of the current local repository folder.
- Copy the files from this package into the ROOT of the existing titan-enterprise repository and allow replacement of files with the same names.
- Do not delete the existing assets/ folder. The updated pages reuse these paths:
  assets/logos/potenza-logo.svg
  assets/logos/favicon.svg
  assets/images/hero-port.jpg
  assets/images/mill.jpg
  assets/images/ic45.jpg
  assets/images/vhp.jpg
- Netlify Forms is enabled in index.html using data-netlify="true". After deploying, submit one test inquiry and check Netlify > Forms. If form submissions are not collected, check that form detection is enabled in the Netlify site settings and redeploy.

DEPLOYMENT:
1. Extract this ZIP.
2. Open the existing local titan-enterprise folder (the one connected to GitHub Desktop).
3. Back up the folder first.
4. Copy the package files into that folder, replacing matching root files.
5. Open GitHub Desktop. Confirm the changed files appear under Changes.
6. Enter commit summary: "TITAN V6 - direct mill purchase model".
7. Click Commit to main.
8. Click Push origin.
9. Open Netlify and wait for the production deploy to finish.
10. Test the home page on potenzaimport.com and submit a test form.
