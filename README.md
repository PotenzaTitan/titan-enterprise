GITHUB UPLOAD GUIDE — TITAN ENTERPRISE V4.1

IMPORTANT:
Do NOT upload this ZIP file itself to GitHub.

1. Download and extract this ZIP on Windows.
2. Open the extracted folder.
3. In GitHub, create a new repository:
   Owner: PotenzaTitan
   Repository: titan-enterprise
   Visibility: Public
   README: Off
   .gitignore: None
   License: None
4. Click "uploading an existing file" or Add file > Upload files.
5. Drag ALL files and folders INSIDE the extracted folder.
6. Confirm that these items appear in the repository root:
   index.html
   style.css
   ic45.html
   vhp.html
   thank-you.html
   404.html
   assets/
   documents/
   _headers
   _redirects
7. Commit changes.
